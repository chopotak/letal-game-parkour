# Как добавлять встроенные уровни

Короткий чеклист, чтобы новые уровни нормально появились в кампании и не сломали замочки.

1. Положи уровень в `src/levels/` отдельным `.js` файлом.
   Пример имени файла: `level-six.js`.

2. Экспортируй уровень как `Object.freeze(...)`.
   Пример:
   ```js
   export const LevelSix = Object.freeze({
     name: "Название уровня",
     difficulty: 3,
     requiresKeyForExit: false,
     physicsMode: "nplus",
     map: [
       "########",
       "#P....D#",
       "########",
     ],
     hazards: {},
     textZones: [],
   });
   ```

3. Обязательные поля:
   - `name` - название, которое видно в меню и сверху во время игры.
   - `difficulty` - сложность от `1` до `5`. В меню она отображается как `Сложность: ***`.
   - `map` - прямоугольная карта, все строки одной длины.
   - `P` - старт игрока.
   - `D` - дверь/финиш.
   - `K` - ключ, если `requiresKeyForExit: true`.

4. Добавь уровень в `src/main.js`:
   - импортируй файл сверху;
   - добавь запись в `FALLBACK_BUILT_IN_LEVELS`;
   - добавь id уровня в порядок сортировки `sortBuiltInLevels()`.

5. Не меняй id уже существующих уровней.
   Прогресс и замочки сохраняются в браузере по id уровня. Если id поменять, игра будет считать уровень новым.

6. Если уровень сделан в редакторе:
   - сохрани его в папку уровней;
   - проверь `name` и `difficulty`;
   - перенеси/подключи его как встроенный уровень по шагам выше.

7. Перед запуском проверь:
   ```bash
   node --check src/main.js
   node tools/validate-level.mjs
   ```

Правило замков простое: первый встроенный уровень открыт всегда, каждый следующий открывается только после прохождения предыдущего в списке.
