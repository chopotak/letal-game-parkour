# Мясной Лабиринт

Мини-демка браузерного 2D-платформера с архитектурой, близкой к тому, как проект обычно режется на классы в C#.

## Запуск

Так как игра использует ES modules, лучше запускать через локальный сервер:

```powershell
cd C:\Users\user\Documents\lol
python -m http.server 8000
```

После этого открыть `http://localhost:8000`.

## Структура

- `src/main.js` - точка входа, связывает все классы.
- `src/core/game.js` - главный игровой цикл и правила уровня, аналог `Game` класса.
- `src/core/physicsWorld.js` - физика персонажа и коллизии.
- `src/config/gameConfig.js` - числа физики: скорость, прыжок, гравитация.
- `src/core/level.js` - загрузка карты, маркеры объектов, динамическое состояние уровня.
- `src/levels/levelOne.js` - большая карта 75x45, комнаты, коридоры и расстановка ловушек.
- `src/entities/player.js` - состояние персонажа.
- `src/entities/effectSystem.js` - частицы, взрывы, пыль.
- `src/rendering/` - весь canvas-рендер и пиксельные спрайты.
- `src/ui/uiController.js` - счетчик смертей, таймер, hint, рестарт.
- `styles/` - CSS-оболочка ретро-телика.
- `tools/validate-level.mjs` - проверка размера карты и привязки скрытых шипов к полу.

## Управление

- `A` / `D` - движение
- `W` - прыжок
- `S` - быстрый спуск в воздухе
- `R` - рестарт
- `K` - показать/скрыть диагностику производительности
- `J` - переключить лимит отрисовки: `30 / 60 / 120 / 165`
- `Esc` - пауза / продолжить

При запуске открывается главное меню с выбором уровня.

Доступные уровни:

- `Уровень 1` - большой троллинг-лабиринт с ключом, фальшивым выходом, шипами и пилами.
- `Уровень 2` - большая комната с шатающимися треугольниками, шипами снизу, красной зоной запуска ракеты и лазером памяти.
- `Мой уровень` - уровень, сохраненный во встроенном редакторе.

## Редактор

В главном меню нажми `Редактор`.

- `Сохранить` - сохранить уровень в браузере через `localStorage`.
- `Тест` - сохранить и сразу запустить пробный запуск.
- `В меню` - вернуться без запуска.
- `Ширина` / `Высота` - изменить размер уровня от `20` до `120` тайлов.
- Колесо мыши - приблизить/отдалить сетку.
- `Shift` + перетаскивание или ПКМ + перетаскивание - двигать камеру редактора.

По умолчанию редактор создает нормальные границы: стены по краям и 3 нижних ряда пола.

Палитра:

- `.` пусто
- `#` стена
- `P` старт игрока
- `D` настоящая дверь
- `E` фальшивая дверь
- `K` ключ
- `C` монетка
- `B` кнопка
- `S` шипы
- `F` падающий блок
- `T` перевернутый треугольник-платформа
- `O` пила
- `R` ракета
- `Z` триггер ловушек
- `L` лазер
- `H` скрытые шипы

## Диагностика микрофризов

Нажми `K` в игре. В левом верхнем углу появится overlay:

- `кадр` - полная длительность кадра. Больше `16.7мс` заметно как просадка на 60 FPS.
- `лимит` - текущий лимит отрисовки. Меняется клавишей `J`.
- `update` - логика игры: физика, ловушки, проверки столкновений.
- `render` - отрисовка canvas.
- `частицы`, `пилы`, `скр. шипы` - сколько активных объектов сейчас работает.
- `длинный` - последние кадры дольше порога из `GameConfig.performance.longFrameMs`.

Открой DevTools браузера и вкладку Console. Игра пишет события `[perf] Длинный кадр` с контекстом: позиция игрока, камера, частицы, активные ловушки, update/render время.

Как читать:

- большой `render`, маленький `update` - тормозит canvas/CSS/масштабирование окна.
- большой `update`, маленький `render` - тормозит логика уровня.
- оба маленькие, но `кадр` большой - вероятны GC, браузер, расширения или системная нагрузка.
